# ZVEREVA — макет сайта салона красоты (Краснодар)

**Смотреть:** https://vutgen.github.io/vuegen-zvereva-krasnodar/

Макет сайта, подготовленный студией vuegen по открытым данным салона (2ГИС, ВКонтакте, онлайн-запись YClients).

- Услуги и цены: короткий прайс по основным услугам; полного прайса на сайте нет.
- Запись: онлайн-запись YClients встроена в страницу (блок «Онлайн-запись»), все кнопки «Записаться» ведут к ней.
- Фото в макете стоковые (Unsplash), заменяются на фото салона.
- Страница скрыта от поисковиков (`noindex`).

Весь контент лежит в `config.js`.
